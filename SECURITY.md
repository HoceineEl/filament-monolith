# Security Policy

## Supported versions

Only the latest major release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Email **contact@hoceine.com** or use GitHub's [private vulnerability reporting](https://github.com/HoceineEL/filament-monolith/security/advisories/new). You will get a reply within 72 hours, and a fix or mitigation plan within 14 days of confirmation.
