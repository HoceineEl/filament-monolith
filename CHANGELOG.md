# Changelog

All notable changes to `filament-monolith` are documented in this file.

## v1.0.0 - 2026-10-08

- Initial release: inset, floating and classic sidebars; compact, default and roomy density; 10 accents plus any brand hex color; 8 base palettes; any Bunny font with an in-panel font picker; Arabic and RTL support; live appearance customizer with config export; per-user server persistence; Filament v4 and v5 support.
